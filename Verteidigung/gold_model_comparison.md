# Gold Heating Model Comparison

This document compares the three gold-particle heating models:

- `heat_equation_gold_lumped_0d.ipynb`
- `heat_equation_gold_2d_pde.ipynb`
- `heat_equation_gold_3d.ipynb`

## Common Physical Inputs

All three models use the same beam, material, and spherical-particle assumptions:

| Quantity | Value |
|---|---:|
| Beam energy | 300 keV |
| Deposited energy fraction | 0.71% |
| Deposited energy per electron | 2.13 keV |
| Total beam current | 50 nA |
| Deposited power | 1.065e-4 W |
| Gold density | 19.32e3 kg/m^3 |
| Gold heat capacity | 129 J/(kg K) |
| Gold thermal conductivity | 317 W/(m K) |
| Sphere radius | 500 nm |
| Ambient temperature | 300 K |
| Sublimation reference temperature | 1275 K |

The deposited power is calculated from total current:

```text
P_dep = E_P I / e_c
```

Radiative cooling uses the full spherical surface area:

```text
P_rad = 4 pi R_sphere^2 epsilon sigma (T^4 - T0^4)
```

For the 2D and 3D PDE models, this is applied as an equivalent volumetric sink:

```text
q_rad = (4 pi R_sphere^2 / V_sphere) epsilon sigma (T^4 - T0^4)
```

## Model Differences

| Model | Geometry | Heat Source | Heat Transport | Main Use |
|---|---|---|---|---|
| 0D lumped | Whole sphere as one temperature | Total deposited power `P_dep` | No spatial diffusion | Fast upper-level estimate and long-time radiation balance |
| 2D PDE | Central circular section | `Scorer_1.csv`, scaled to `P_dep / V_sphere` | In-plane diffusion only | Faster spatial approximation using original 2D scorer |
| 3D PDE | Full sphere | `Scorer_1_3d_axisymmetric.csv`, scaled so integral equals `P_dep` | Full 3D diffusion | Most complete spatial model |

## Governing Forms

### 0D Lumped Model

```text
m Cp dT/dt = P_dep - 4 pi R^2 epsilon sigma (T^4 - T0^4)
```

The whole particle is treated as one thermal mass, so internal temperature gradients are ignored.

### 2D PDE Model

```text
rho Cp dT/dt
= k(d2T/dx2 + d2T/dy2)
- (4 pi R_sphere^2 / V_sphere) epsilon sigma (T^4 - T0^4)
+ Q_3D(x,y)
```

The source shape comes from `Scorer_1.csv`. The source is normalized so the mean inside the circular gold domain equals `P_dep / V_sphere`.

### 3D PDE Model

```text
rho Cp V_sphere dT/dt
= k V_sphere laplacian(T)
- 4 pi R_sphere^2 epsilon sigma (T^4 - T0^4)
+ V_sphere Q_3D(x,y,z)
```

The source shape comes from the corrected axisymmetric 3D scorer and is normalized so:

```text
integral(Q_3D dV) = P_dep
```

## Numerical Results

For `I_total = 50 nA`, the shared deposited power is:

```text
P_dep = 1.065e-4 W
```

The uniform lumped radiation-balance equilibrium is:

```text
T_equilibrium = 4944.80 K
```

Short-time temperature results:

| Model | Time | Center Temperature | Maximum Temperature |
|---|---:|---:|---:|
| 0D lumped | 1.5 ns | 300.1224 K | 300.1224 K |
| 0D lumped | 3.0 ns | 300.2448 K | 300.2448 K |
| 2D PDE | 1.5 ns | 300.0707 K | 300.0718 K |
| 3D PDE | 3.0 ns | 300.0829 K | 300.0847 K |

## Interpretation

The 0D model heats fastest because it assumes the whole sphere has one uniform temperature and does not resolve spatial redistribution of heat. It is useful for a simple energy-balance estimate and for estimating the long-time radiation-only equilibrium.

The 2D PDE model includes spatial diffusion in the central plane and uses the original 2D scorer as the deposition shape. It is more realistic than 0D for local heating patterns, but it cannot represent heat spreading in the third spatial direction.

The 3D PDE model is the most complete spatial model. It uses the corrected 3D axisymmetric scorer and allows heat to diffuse in all three directions. For the same 50 nA current, it remains close to ambient on the nanosecond time scale.

At 50 nA, all three models predict only a small nanosecond-scale temperature rise. The large value of `T_equilibrium` belongs to the simplified long-time 0D radiation-balance model; the 2D and 3D simulations were not run to steady state.
