# Workspace identity: AI/agent skills sandbox

This repository is treated as an AI/agent skills sandbox, not a research or application project. The physics/thesis-defense material (`Verteidigung/`, `T3D_csv/`, root notebooks, `requirements.txt`) is **legacy** and is relocated to a sibling folder (`../Verteidigung_Research/`) so the sandbox tooling becomes the visible top level. The research remains recoverable from origin history.

## Considered Options

- **Research-first workspace** (tooling bolted on) — rejected: the day-to-day work here is skill/agent authoring, not the physics.
- **Mixed mono-workspace** (both first-class) — rejected: the mixing is exactly what produced the cluttered, 2,560-file root.
- **Sandbox-first, research relocated** — chosen.

## Consequences

- The research must be moved deliberately (it is tracked and pushed); origin history preserves every file.
- The root README is rewritten to describe the sandbox, not the old scripts.
